# WHOAMI
# WHOAMI  > personal threat detection for one (1) human. > it scanned your device. it found one threat. it's you.  **WHOAMI** is a concept antivirus that went the other way. It doesn't protect your computer, it reads it: your device, your graphics chip, your battery, your city, your clock, how you move your mouse, how many times you came back. Then it says it all back to you, politely. Then the page starts to break: the scroll locks, the letters fall, the screen crashes, the files get deleted. And every time something breaks, a black cat made of characters jumps in to laugh at you, scare you, or ask for your name.  It's a horror site that runs entirely in your own browser. Nothing is installed, nothing is sent anywhere, and on the last page there's a button that deletes everything it remembers about you, for real.  concept, design & code by **ghostly.grl ♥**  ---  ## contents  - [the idea](#the-idea) - [how it knows you](#how-it-knows-you) - [the cat](#the-cat) - [the look](#the-look) - [the pages](#the-pages): [home](#home) · [scan](#scan) · [cam](#cam) · [files](#files) · [log](#log) · [nine](#nine) · [exit](#exit) - [always on](#always-on) - [privacy](#privacy) - [run it](#run-it) - [structure](#structure) - [stack](#stack)  ---  ## the idea  `whoami` is the command a computer answers with the name of whoever is using it. The site asks the same question back, and answers it better than you'd like.  The rules of the world:  - **it knows you.** every page is built out of your own details. the files on its fake desktop have your name in them, the receipt it prints has your computer on it, the diary is about what you did five minutes ago. - **it breaks.** the site behaves like it's infected. the scroll locks, dialogs lie (both buttons say *allow*), the screen crashes into a grey panic page, a second cursor moves on its own. - **the cat is the voice.** whenever something breaks, the cat appears and says something ironic, unsettling or rude. it never explains itself. - **there's always a way out.** even if it takes five doors to find it.  ---  ## how it knows you  Everything comes from what a browser is allowed to say, plus one trick per way of opening the site.  | what | where it comes from | |---|---| | your name | see below | | your computer's name | `serve.py` (only when run locally), otherwise the device type | | system, browser | the user agent | | graphics chip | WebGL (`apple m1`, `nvidia geforce…`) | | cores, memory | `navigator.hardwareConcurrency`, `deviceMemory` | | battery, charging | the Battery API (where it exists) | | city, local time | your timezone (`Europe/Rome` → *rome*) | | screen, pixel density, dark mode | `screen`, `devicePixelRatio`, `prefers-color-scheme` | | how much room your disk gives the browser | `navigator.storage.estimate()` | | visits, time spent, metres of mouse, clicks, keys, scroll, tab switches | counted by the site itself, kept in your browser | | your face, your voice | only on [cam](#cam), only if you say yes, never stored |  **Your name**, in this order:  1. **`serve.py`**: the local server has one secret door, `/whoami`, that answers only to `127.0.0.1`. It reads the full name of the Mac's owner (`id -F`), the account (`pwd`) and the computer's name (`scutil --get ComputerName`). So whoever runs it on their own Mac gets *hi, martina.* or *hi, luca.* 2. **double-click** (`file://`): the file's own path gives the account away. `/Users/martinasacchetto/…` becomes *martina sacchetto*, `giulia.rossi` becomes *giulia rossi*. Account names written as one word are split using a list of common first names. 3. **it asks.** On a published website none of that exists, so a system box asks *what's your name?*: during the scan on the home, or a few seconds in on any other page. People always answer. It's kept, so next time: *you told me last time. i kept it.* Say no and it calls you **you**, and asks again next visit.  ---  ## the cat  There is no picture of the cat. `js/cat.js` draws it from shapes on every frame (two ellipses for the head, triangles for the ears, eyes with slit pupils and a highlight, a nose, a mouth with fangs, whiskers) and turns each cell of a grid into a character: dense fur on the inside (`#%@&$8B`), lighter characters on the edges (`:;*+=~-`), `o` and `@` in the eyes.  Because it's drawn, it can do things a picture can't: blink, follow your cursor (or your face, on cam), talk, glitch, and change mood.  Moods: `idle` · `stare` · `sleep` · `smug` · `laugh` · `angry` · `wide` · `sad` · `dead`  ```js const cat = new WH.Cat(preElement, { w: 64, h: 32, mood: 'smug' }); cat.mood('laugh', 1500);   // laughs, then goes back to idle after 1.5s cat.talk(1000);            // the mouth flaps for a second cat.glitch(400);           // rows slip sideways cat.lookAt(0.4, -0.2);     // look somewhere (-1 → 1), instead of at the cursor ```  The same engine draws every cat on the site: the little **cat.exe** window in the corner, the giant one that pops in when something breaks, the eyes that fill a whole screen on the home, the cat on a video call, the one that's still there when you pull the plug. It only draws while it's on screen.  ---  ## the look  One world: **a photocopy.** Paper, ink, grain over everything, and one colour that shouldn't be there: the pink of an infection.  | | | |---|---| | paper | `#efede8` | | ink | `#0d0d0d` | | infection pink | `#ff1f9b` | | dark pink | `#c4006f` | | highlighter yellow (rare) | `#ffe600` |  | type | used for | |---|---| | **Archivo** 62% wide, black | posters, giant words (WHO / AM / I?, EXIT, LOG) | | **Archivo** 125% wide, italic | headings | | **Courier Prime** | the body text, like a typed report | | **EB Garamond** italic | the cat's voice | | **JetBrains Mono** | terminals, labels, data | | **VT323** | the crt game over screen |  The cursor is a crosshair that prints its own coordinates. Poke it, right-click, copy something, go idle, scroll too fast, go back up, head for the close button, or leave the tab: it has something to say, usually with your name in it - **the footer is a terminal.** Type `whoami`, `ls`, `pwd`, `uname`, `sudo`, `rm -rf`, `kill -9`, `exit`, `hi`… the cat answers - the **tab title** calls you back while you're away (*martina?*, *come back*, *reading MacBook Air di Martina…*) and the favicon turns into an eye - the **crosshair cursor** prints its coordinates - **↑ ↑ ↓ ↓ ← → ← → b a** turns on sudo mode: pink forever - everything you do is written into the diary on the [log](#log) page - `WH.help()` in the console  ---  ## privacy  WHOAMI is designed to feel like it took everything, while taking nothing.  - there is no backend, no analytics, no cookies. The only network requests are the page itself, the fonts, GSAP and Lenis - what it remembers (your name if you typed it, visits, counters, the diary, the mouse path) lives in your browser's `localStorage` / `sessionStorage`, under keys starting with `wh-` - the camera and microphone are used only on cam.html, only after you accept, and every frame is turned into characters in a tiny canvas and thrown away about 20 times a second. Nothing is recorded or uploaded. The mugshot png is drawn and saved on your own machine - `serve.py`'s `/whoami` door answers only to `127.0.0.1` - **forget me** on the log page deletes all of it  ---  ## run it  **the full experience** (a Mac, Python 3): the cat knows your full name and your computer's name.  ```bash python3 serve.py ```  → http://localhost:5820 (a different port: `python3 serve.py 8080`)  **double-click** `index.html`: works without a server; the name comes from your account.  **published** (GitHub Pages or any static host): works as is; the cat asks your name.  There's no build step and no dependencies to install. Best on desktop Chrome, Safari or Firefox; it works on phones too.  ---  ## structure  ``` index.html            home scan.html             the full scan cam.html              incoming call (camera + microphone) files.html            your files log.html              the log nine.html             nine lives exit.html             try to leave  css/style.css         shared: paper, ink, pink, grain, type, cursor, nav, cat.exe, pop-ups,                       dialogs, crash screen, black marker, footer terminal css/home.css          · css/scan.css · css/cam.css · css/files.css css/log.css           · css/nine.css · css/exit.css   one per page  js/cat.js             the ascii cat engine (WH.Cat) js/main.js            WH: what the site reads about you, your name, the counters, the diary,                       boot, cursor and ghost cursor, cat.exe, pop-ups, breaks, dialogs,                       tab title, konami, footer terminal js/home.js            · js/scan.js · js/cam.js · js/files.js js/log.js             · js/nine.js · js/exit.js   one per page  serve.py              local server + the /whoami door favicon.svg img/                  photos (see img/README.md) VIBES/                the moodboard ```  ---  ## stack  HTML, CSS and vanilla JavaScript · [GSAP 3.12.5](https://gsap.com) + ScrollTrigger · [Lenis 1.1.13](https://lenis.darkroom.engineering) · Canvas 2D · WebGL (only to read the chip's name) · getUserMedia + Web Audio (cam) · Battery and Storage APIs · Python 3 standard library (serve.py) · Google Fonts: Archivo, Courier Prime, EB Garamond, JetBrains Mono, VT323  Respects `prefers-reduced-motion`.  ---  ```         /\_/\        ( @.@ )      $ whoami         > v <       you. obviously.        /|###|\ ```  concept, design & code by **ghostly.grl ♥**
